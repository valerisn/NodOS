# Security research

We welcome good-faith security research on NodOS. If you follow the rules
below, the maintainers will not pursue legal action against you for it and will
work with you on a fix.

- Test against your own installation, never against someone else's.
- Do not access, change or destroy data that is not yours.
- Do not run denial-of-service tests against systems you do not own.
- Report privately as described in [SECURITY.md](../../SECURITY.md) and give us
  a reasonable time to fix the problem before you publish.
- Stop and report if you reach credentials or personal data by accident.

This statement covers the NodOS project only. It cannot grant permission for
systems or services run by other people, including GitHub.

Fixed issues are written up in [security issues](../../security%20issues/README.md).
