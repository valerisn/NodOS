# Code of conduct

NodOS is a technical project. We expect contributors to keep it a place where
people can do good work.

**Expected:** be respectful, assume good faith, give specific and kind feedback,
accept disagreement about code without making it personal.

**Not acceptable:** harassment, personal attacks, discriminatory language or
jokes, publishing someone's private information, sustained disruption of
discussions.

Maintainers may edit or remove comments, close threads, and block accounts that
violate these rules. To report a problem, contact the maintainers through a
private GitHub security advisory or a direct message to a maintainer. Reports
are handled confidentially.

This applies to issues, pull requests, discussions and any space where someone
represents the project.
